Worker 将 HTTP 状态和完整供应商 JSON 作为 `native-provider-v1` 回执保存。

模型请求与回包各有 32 MiB 传输保护；任务接口允许 32 MiB JSON、16 MiB 正文。
这些是内存/传输界限，不是模型 token 限额。旧引擎首次接受的任务仍限制 40000 字节；
检查位于首次插入事务内，切换默认引擎不影响已存在的大请求幂等重试。
